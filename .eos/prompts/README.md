# Prompts de trabajo EOS

**Autoría y dirección: Pierre R. Boss (oprbguitar). Desarrollo documental asistido por IA.**

Estos prompts convierten una intención en una tarea acotada. Completa las variables antes de ejecutarlos. Un campo vacío de autorización significa que la operación aún no está autorizada; no se deduce un permiso del título del prompt. Los prompts no sustituyen instrucciones del host, constitución, perfil ni manuales.

Usa [BOOTSTRAP](BOOTSTRAP.md) para la primera conversación del proyecto y [TASKS](TASKS.md) para tareas específicas. Las skills canónicas están en [skills](../skills/README.md). No copies datos sensibles completos: proporciona referencias locales autorizadas y ejemplos minimizados.
